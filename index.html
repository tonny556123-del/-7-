💡 小提示：試著點擊「x = a (重疊試試！)」把 P 與 A 重疊，觀察斜率算式會遇到什麼困境！

💡 為什麼需要極限 (lim)？

  1. 0 / 0 困境：直接代入 x = a（兩點重疊）會得到 0 / 0，分母為 0 沒有意義，而且一個點也連不出直線。
  2. 微距觀察：切換比較上方的 a + 0.001 與 a − 0.001，只要讓 P 無限靠近 A 但永遠不重疊（x ≠ a），割線斜率就會穩定趨近切線真實斜率！
  3. lim 的意義：因此數學在割線斜率前加上 lim (x → a)，代表「讓 x 無限逼近 a，但 x ≠ a」，成功避開 0 / 0 又精準抓出切線斜率！

🎓 核心結論：切線與導數的定義

為了找出通過 A(a, f(a)) 的切線並避開 0 / 0，我們讓割線上的動點 (x, f(x)) 無限逼近 (a, f(a))（且 x ≠ a）：

  • 割線 AP 的極限位置，就是通過點 A 的「切線」。
  • 割線斜率的極限值，就是切線斜率，定義為函數 f(x) 在 x = a 處的導數，記作 f′(a)。
